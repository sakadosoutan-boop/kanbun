# 楚漢の章 —— 人物と舞台の考証メモ

授業で「なぜこの姿なのか」を聞かれたときの答えにもなるよう、本文の根拠を先に置く。

京劇『霸王別姫』の霸王（黒い隈取・霸王盔・靠旗）は後世の舞台の姿なので取り入れず、
「黒と金の甲・赤い纓・赤い披風」という色の印象だけを借りた。

## 衣と甲

- **深衣**：交領右衽（右の身頃を下に、左を上に重ねる）。襟元に中衣の白をのぞかせる。
  **曲裾**は前身頃が体に巻きつく形で、縁の帯が右腰から前を斜めに横切って左後ろへ回る（裾の面に沿わせた帯で描く）。
- **袖**：肩から袂（たもと）へふくらみ、袖口（袪）で細くなる。袂は毎フレーム重力の向きへ垂らす。
  立つときの基本姿勢は**拱手**（両手を胸の前で袖の中に重ねる）で、漢の立俑の姿にならった。坐すときは手を腿に置く。
- **履**：長衣の人物は裾から**歧頭履**（つま先が二つに割れて反る。馬王堆の出土品）の先がのぞく。
- **甲**：小札を綴じた甲。札は上の段が下の段に重なるよう少し反らせ、隙間から綴じ紐の色が見える。
  肩には披膊、腰から下は甲裙。兵は袴に行縢（脚絆）を巻く（楊家湾漢墓の兵俑）。

## 舞台

- **鴻門の宴の帳**：座次は本文どおり（項王・項伯は東嚮、亜父は南嚮、沛公は北嚮、張良は西嚮して侍す）。
  生成りの帷に朱の帽と錦の縁、束ね紐。項王と亜父の背には黒漆に朱の雲気文の屏風。
  一人ずつの席（錦の縁の敷物）と低い漆の案、案の上に耳杯・盤・箸。青銅の樽、兵器架、灯台。
- **帳中（覇上）**：漆の案に竹簡（巻いたものと広げたもの）、屏風、兵器架。
- **雒陽南宮**：段の上の榻と屏風、左右の青銅器、臣下の列のあいだの緋の敷物。

## 見た目の処理

- 布・漆・肌の色は sRGB で指定して線形に直し、ACES のトーンマッピングで仕上げる。
- 冠と兜は影を落とさない設定にして、目元が暗くつぶれないようにした。
- 画面の周辺減光とごく弱い粒子は CSS の重ね絵（`.km-ov::before`）で足す。描画の負荷は増えない。
- 台詞のたびに、話し手は右手で身ぶりをし、ほかの人物はそちらへ顔を向ける（`KoumonStage3D.speaker`）。
