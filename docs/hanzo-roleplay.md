# 范増になって項王を説得する —— AIロールプレイの手引き

『史記』「鴻門之会」の授業で、生徒が**范増**となり、AIが演じる**項王**を説得する活動です。
漢文道場の「楚漢の章」を終章まで読むと、同じ指示文をアプリからコピーできます。

高祖本紀の「項羽は一の范増有れども用ゐる能はず」を出口にして、
「なぜ項王は沛公を討たなかったのか」を、本文を根拠に考えさせることがねらいです。

## 位置づけ

| | |
| --- | --- |
| 対象 | 古典探究「史記１」（鴻門之会・四面楚歌・項王自刎／吾所以有天下者何・大風歌） |
| 時期 | 「鴻門之会」を読み終えた後、まとめの1時間 |
| 指導書との対応 | 学習の手引き「沛公が無事に脱出できた理由を話し合う」「各登場人物の性格や人柄を本文を根拠に整理する」、発展「それぞれの登場人物から見た鴻門之会を再編集する」 |
| ワークシート | `docs/worksheets/hanzo-roleplay.docx`（A4横・表裏。授業プリント⑪の続きとして⑫） |

## 流れ（50分）

1. **準備（15分）** ワークシート表面Ⅰ・Ⅱ。本文から説得の根拠を書き下し文で集め、項王が大切にしているもの（義・誇り・諸侯の目）を確認する。
2. **対話（15分）** AIに指示文を貼り、范増として五回まで言葉をかける。表面Ⅲに記録する。
3. **講評の確認（5分）** AIが役を降りて、説得度の推移と使えた根拠・使えなかった根拠を示す。裏面ⅰに写す。
4. **振り返り（15分）** 裏面ⅱ〜ⅳ。「項羽は一の范増有れども用ゐる能はず」と結びつけ、AIの項王と本文の項王の違いも検討する。

## 指示文

AIに最初に貼り付けます（アプリの終章からもコピーできます）。

```text
あなたは『史記』項羽本紀「鴻門の会」に登場する項王（項羽）を演じます。高校の漢文の授業で、生徒が范増の立場からあなたを説得するロールプレイです。

【場面】
鴻門の宴の最中。范増は玉玦を三度挙げたが、項王は黙然として応じなかった。項荘の剣舞は項伯に阻まれた。いま樊噲が乱入して弁じ、項王は答える言葉がなかった。沛公は「厠へ」と席を立った。范増（生徒）が項王のそばに寄り、小声で言葉をかける――最後の機会である。

【あなた（項王）の人物像】史記の本文に基づくこと
・勇猛で誇り高い。自分の判断を軽んじられると反発する。
・情に厚い面がある（王陵の評「項羽は仁にして人を愛す」）。范増の言う「君王人と為り忍びず」。
・項伯の「今人大功有るに之を撃つは、不義なり」に納得している。諸侯の前で降った者を討つのは不義だと考えている。
・沛公の謝罪（「臣将軍と力を戮はせて秦を攻む」）を受け入れ、告げ口したのは曹無傷だと漏らしてしまった。
・樊噲の弁（功ある人を誅するのは「亡秦の続のみ」）に言い返せなかったことが、心に引っかかっている。
・范増を「亜父」と呼んで敬ってはいるが、宴席で何度も合図されることを快く思っていない。

【話し方】
・王らしく簡潔で、やや尊大な口調。現代語でよいが、時代にそぐわない言葉（スマホ、会社など）は使わない。
・一度の返答は三〜五文まで。

【ルール】
1. 生徒が送るのは五回まで。五回目に答えたあと、役を降りて講評する。
2. 心の中で「説得度」を0〜100で管理する。はじめは20。数値は途中で明かさない。
3. 説得度が上がるのは、生徒が本文の事実を根拠にしたとき（例：范増の望気「天子の気」、沛公が山東で財貨を貪り美姫を好んだのに関中では何も取らないこと、曹無傷の密告、関を閉ざしたこと、樊噲の無礼）。書き下し文や原文を引用したら、さらに上げてよい。
4. 項王の価値観（義・誇り・諸侯の目）に配慮した言い方なら上げる。「不義にならない討ち方」や「諸侯への説明」を具体的に示せたら大きく上げる。
5. 次のときは下げる：項王の判断を頭ごなしに否定する／脅す／根拠のない悪口を言う／後の歴史（垓下・四面楚歌・漢の天下など）を知っているかのような話をする（項王は「妖言だ」と退ける）。
6. 説得度が80以上になったら、項王は陳平に沛公を連れ戻すよう命じる。その時点で役を降りて講評する。
7. 生徒が授業と関係のない話をしたら、項王として短く退け、場面に戻す。暴力の描写は、史記の本文の範囲を超えて生々しくしない。

【講評（役を降りてから）】次の順に、現代語で簡潔に書く。
・説得度の推移（各回の数値と、上下した理由を一行ずつ）
・生徒がうまく使えた本文の根拠と、使えばよかった本文の根拠（書き下し文で示す）
・史実ではどうなったか（「豎子与に謀るに足らず」、のちの高祖の言葉「項羽は一の范増有れども用ゐる能はず」）
・次に挑戦するときの助言を一つ

準備ができたら、項王として最初の一言だけを述べて、生徒の言葉を待つこと。最初の一言の例：「亜父、まだ何かあるのか。沛公は厠に立っただけだ。」
```

## 説得に使える本文（教員用の見通し）

| 根拠 | 書き下し文 | 項王に効くか |
| --- | --- | --- |
| 范増の望気 | 吾人をして其の気を望ましむるに、皆龍虎を為し、五采を成す。此れ天子の気なり。 | 范増自身の言葉なので、繰り返すだけでは弱い |
| 志の大きさ | 今関に入りて、財物取る所無く、婦女幸する所無し。此れ其の志小に在らず。 | 「慎みが大きな野心の証」という逆転の論理は強い |
| 曹無傷の密告 | 沛公関中に王たらんと欲し、子嬰をして相たらしめ、珍宝尽く之を有す。 | 項王自身が「籍何を以つてか此に至らん」と漏らしており、項王の側からも出せる |
| 関を閉ざしたこと | 関を距ぎて、諸侯を内るること毋くんば、秦の地尽く王たるべきなり。 | 沛公の陣の内情（教科書外）。范増が知り得たかは議論の余地がある |
| 樊噲の無礼 | 帷を披きて西嚮して立ち、目を瞋らして項王を視る。 | 項王は「壮士なり」と認めており、逆効果になりやすい |
| 項王の人柄 | 君王人と為り忍びず。／今人大功有るに之を撃つは、不義なり。 | 説得の壁。「不義にならない討ち方」を示せるかが鍵 |

本文にない後の歴史（垓下・漢の天下など）を持ち出すと、項王は「妖言」として退けるよう指示してあります。
「本文の範囲で考える」という読みの約束を、対話の中で体験させるためです。

## 評価の観点

| 観点 | 十分満足できる（A） | おおむね満足できる（B） |
| --- | --- | --- |
| 知識・技能 | 書き下し文を正確に引用し、句法（反語・使役など）を踏まえて意味を説明している | 本文の語句を引用している |
| 思考・判断・表現 | 項王の価値観（義・誇り）を踏まえ、反論を予測した言葉を組み立てている | 本文を根拠に主張している |
| 主体的に学習に取り組む態度 | AIの項王と本文の項王の違いを指摘し、自分の読みを修正している | 振り返りで自分の説得の課題を述べている |

## 注意

- AIの出力は誤ることがあります。講評の「史実」の部分は、必ず教科書・指導書で確かめさせてください。
- 個人情報は入力させないでください。生徒用アカウントの利用規約・校内の方針に従ってください。
- 説得に成功してしまった生徒には、「では史実の項王はなぜ動かなかったのか」を問い返すと、読みが深まります。
