# 漢文道場 — KANBUN DOJO

高校生向けの漢文トレーニング Web アプリ。再読文字・句法・返り点・置き字・漢詩・故事成語を、
ゲーム感覚で反復できます。利用時はビルド不要・依存ゼロ・オフライン動作。

`index.html` をブラウザで開くだけで動きます。

| 厳選問題 | 100 | 識別・訳出などの設問。第二巻の文脈問題24問を含む |
| 書き下しの誤答 | 92 句形 | 句法だけを取り違えた「一字違い」の誤答（手書き） |

## 今回の追加

- **第二巻・諸子と詩人の試練**：荀子、孟子、韓非子、荘子、陶淵明、王之渙、杜甫、司馬遷。新作の文脈問題を各3問、応用問題と組み合わせて出題。一問40秒、正解6〜8回で突破します。
- **クリア記録の引継ぎ**：保存キー `kanbun-dojo:v1` と第一巻の関門IDを維持。第一巻クリア済みなら第9関門から始まり、免許皆伝はそのまま。第二巻クリアで「古典探究」を獲得します。関門一覧から突破済みの相手に再挑戦できます。
- **初回の3分入門**：読む順の見本 → レ点をタップ → 時間制限なしの自力3問。ホームから読み直せます。
- **今日の5問・弱点と復習予定**：パズルも元の操作形式で復習。正解後は翌日・3日後・7日後と間隔を広げて確認します。
- **途中再開**：一問ごとの記録と進行中の操作を保存。「続きから」で回答済みの解説や関門突破画面も再開できます。保存できないときは警告を表示します。
- **学習設定**：句法・漢字ドリルの時間制限を外せます。道場破りと実力テストは制限あり。制限なしドリルの自己ベストは別に保存します。
- **誤答から学ぶ**：見直すポイント、関連講座、図鑑、類題3問への導線を追加。新作24問は各誤答に個別の説明があります。
- **実力テスト**：訓読・識別4、再読3、句法6、漢詩3、故事2、漢字2。難度の比率も固定し、分野別結果と前回得点を表示します。旧ベストは残りますが、以前とは出題配分が異なります。

記録は同じブラウザ・同じ保存元に保存されます。既存のURLで更新するか、利用中のHTMLを同じ場所で差し替えてください。別のURL・別ブラウザへの自動移行はありません。

## 遊び方（モード）

- **訓読の基本** … 返り点・置き字・書き下しのきまり
- **再読文字ドリル** … 未・将・且・当・応・宜・須・猶・由・盍
- **道場破り** … 第一巻の基礎8関門、第二巻の応用8関門に挑む対戦形式
- **句法ドリル** … 全句法から通しで 15 問、一問 25 秒（制限なしも選択可能）
- **返り点ルート** … 返り点にしたがって読む順に漢字をタップ
- **置き字ハンター** … 文中の「読まない字」をすべて選ぶ
- **書き下し組立** … 語のかたまりを並べて書き下し文を作る
- **漢詩の間 / 故事成語 / 頻出漢字の読み**
- **弱点復習** … 直近で誤答した問題を形式別に練習。予定日の来た復習も選べる
- **実力テスト** … 全範囲から 20 問、百点満点で判定

段位（素読 → 五級 → … → 皆伝）、連続学習日数、称号、突破した関門、自己ベストは
`localStorage` に保存されます。サーバーへは何も送信しません。

## 学びの記録

学習量を、漢文の道具立てで見えるようにしています。

**読んだ漢文の字数**　問題に出てきた漢文の漢字を数えて積み上げます。単位を「字」にすることで、
詩の分量にそのまま言い換えられます（五言絶句は 20 字、五言律詩は 40 字、七言律詩は 56 字、
『千字文』はちょうど 1000 字）。「5,958 字＝五言絶句 297 首ぶん」のように出ます。

**竹簡（ちくかん）**　紙が普及する前、漢文は竹の札に書いて綴じられていました。
一枚におよそ 30 字、30 枚で一巻として、読んだ字数を竹簡の束に見立てて表示します。
「あと 12 字で次の一枚が綴じられます」と、次の目標が具体的に出ます。

**日々の墨あと**　直近 12 週間の学習量を、濃淡のある升目で表します。たくさん解いた日ほど
墨が濃くなります。

**分野別の習熟**　濃い帯＝日をあけて定着を確認した問題、薄い帯＝一度でも解いた問題。
最初の正解の後、翌日以降とさらに3日後以降に正解すると定着とします。短時間の連打では増えません。
以前の正誤回数も保持し、これからの復習で定着を確認します。母数は実際に出題できる問題と完全に共通です。

**収録内容の踏破**　句形 100・漢詩 12・故事成語 38・頻出漢字 101 のうち、いくつに触れたか。

**関門の面々**　道場破りで倒した相手が並びます。未突破は「？？？」のまま。

## 表示

**縦書き**　漢文の本文（設問の白文・訓読文、漢詩、句法図鑑の例文、返り点パズル、置き字ハンター）は
既定で縦書きになります。返り点は伝統どおり字の左下に付き、漢詩は句が右から左へ列で並びます。
設問文・選択肢・解説は横書きのままにしています（画面の狭い端末で読みやすさを損なわないため）。
ヘッダーの「縦／横」ボタンでいつでも切り替えられ、設定は保存されます。

縦書きは `writing-mode: vertical-rl` で組んでいますが、この指定は要素の inline サイズ
（＝画面上の高さ）が確定していないと 1 列に潰れ、`height: max-content` も効きません。
そのため本文の字数を `--n` として CSS 変数で渡し、そこから必要な高さを計算しています。
画面に収まらない長さは列を折り返します。

**端末別レイアウト**

| 端末 | レイアウト |
| --- | --- |
| スマホ縦 | モードカードを横並びの 1 列に。漢文は本文の上に縦組み |
| スマホ横 | 縦の余白を詰めて一画面に収め、漢文の柱の高さを抑える |
| タブレット縦 | 2 列、本文の文字を少し大きく、幅を絞る |
| タブレット横・PC | 問題を 2 カラムにして、漢文を右の柱・選択肢を左に置く |

セーフエリア（ノッチ）とタッチ端末のタップ領域にも対応しています。

## 道場破り

漢文の故事や詩に出てくる人物・生き物が関門として立ちはだかります。相手には「気」があり、
正解するたびに削れ、ゼロにすれば突破。こちらの体力は 3 で、誤答か時間切れで 1 減ります。
関門ごとに出題分野が決まっており（蛙＝訓読と否定、燕雀＝疑問と反語、矛盾の商人＝二重否定と
部分否定、李白＝漢詩、孔子＝全分野…）、順に難しくなります。突破した関門は保存され、
次回は続きから始まります。相手が名乗る一句はすべて原典からの引用で、書き下しと出典を添えています。

## 出題ロジック

`src/js/quizgen.js` がデータから 4 択を生成します。

- 読みを問う設問では**漢字だけ**を提示する。訓点つきの表記（`未ダ〜ズ`）には
  送り仮名が入っており、それを出題文にすると答えが書いてあるのと同じになるため、
  各句形に漢字だけの表記（`bare`）を持たせて出し分けている
- **書き下し文の誤答は手書き**（`src/data/misyomi.js`）。文末だけを別の句法に
  取り違えた形を並べる（「暮れんとす」に対して「暮るべし／暮れず／暮れんや」）。
  ここを自動生成すると活用が崩れて「暮れべし」のような明らかな誤りになり、
  かえって消去法で解けてしまうため、規則生成はやめて人手で書いている。
  誤答を用意していない句形では書き下し問題を出さない
- ほかの誤答は原則として**同じ分類の中から**選び、易しくなりすぎないようにする
- 正解と文字集合が 8 割以上重なる選択肢は「実質同じ答え」として除外する
  （手書きの一字違いの誤答は例外として許可）
- **出典・作者を単独で問う設問は置かない**。入試での比重が低いため、出典は解説や
  図鑑・漢詩集で「読む情報」として示すだけにしている
- 練習は苦手度による重み付き抽選。実力テストは分野・難度を固定して抽選
- 漢字の全ての有効な読み、漢詩の全ての対句を誤答候補から除外
- 問題カタログは決定的に構成。選択肢を用意できない問題を習熟率の母数に含めない

再読文字は読みが重なる組（将／且、当／応、猶／由）があるため、逆引き（読み・意味 → 漢字）は
答えが一つに定まるものだけを出題します。二度目の読み・接続する活用形を問う設問も用意しています。

## 開発

```sh
npm ci
npx playwright install chromium
node tools/validate.mjs   # データ整合性チェック
node tools/build.mjs      # dist/index.html（単一ファイル版）を生成
npm test                  # データ検証・単体・回帰・全モードのスモーク
```

Windowsでインストール済みのEdgeを使う場合は、PowerShellで `$env:PW_CHANNEL='msedge'` を設定して `npm test` を実行できます。Playwrightは開発依存として固定しています。テスト画像は `.test-output/` に出力します。

`tools/unit.test.mjs` は別解の採点、出題と母数の一致、パズル復習、即時保存、間隔をあけた定着、試験配分を検査。
`tools/regression.mjs` は中断取消・再開時の二重計上防止・旧セーブから第二巻全クリアまでを実ブラウザで検証します。

`validate.mjs` は形式的なチェックだけでなく、内容の裏取りも行います。たとえば漢詩は

- 五言／七言・絶句／律詩と実際の字数・句数が一致するか
- `rhyme` に登録した押韻字が、本当にその句の末字になっているか
- 押韻の位置が原則（五言＝偶数句末／七言＝第一句末と偶数句末）どおりか、
  例外なら `regular: false` が立っているか
- 律詩なら頷聯（3・4 句）と頸聯（5・6 句）の対句が登録されているか

を機械的に検証します。ほかにも、置き字データの字が代表 7 字に含まれるか、書き下しの誤答に
正解が混じっていないか、関門の出題分野が実在する分類かなどを確認します。

`smoke.mjs` は全モードの通し実行に加えて、中断ダイアログが開いて「中断する／やめる」の
どちらでも正しく動くこと、道場破りが決着することも検査します。

## 構成

```
index.html            エントリーポイント
src/styles/app.css    スタイル（和モダン／ライト・ダーク対応）
src/data/*.js         コンテンツ（window.KUHO などのグローバルに定義）
                      kuho / misyomi / mondai / foes / kaeriten / okiji /
                      narabekae / kanshi / koji / kanji / lessons
src/js/store.js       進捗・段位・称号・苦手度・日別の学習量の管理
src/js/quizgen.js     問題生成
src/js/app.js         画面遷移とゲームエンジン
tools/                検証・ビルド・テスト
```

データはすべてプレーンな JS 配列なので、`src/data/` に項目を足せばそのまま出題対象になります。

## 訓点の書き方

データ中の返り点は `^` を前置して明示します（`未^レ聞^二其名^一`）。
本文にも「一見」「二月」のように返り点と同じ字が現れるため、自動判別はしていません。
描画時は直前の一字を `<span class="kc">` で包み、返り点を絶対配置します
（横書きなら右下、縦書きなら左下）。

なお縦書きには縦方向のメトリクス（`vmtx`）を持つフォントが必要です。
Hiragino・Yu Mincho・Noto Serif JP などは問題ありませんが、一部 Linux の既定 serif には
これが無く文字が重なってしまうため、フォント指定の末尾に IPA 系を保険として入れています。

## 確認ダイアログ

中断や記録の消去には自前のダイアログを使っています。`window.confirm` は埋め込み表示
（サンドボックス化された iframe）でブロックされることがあり、押しても何も起きない
状態になるためです。

## 出典について

例文・漢詩・故事成語はすべて古典からの引用で、出典を明記しています。
書き下し文・現代語訳・解説は学習用に付したものです。
